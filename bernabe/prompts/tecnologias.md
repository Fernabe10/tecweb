# Generador de Guías sobre Tecnologías para Desarrollo Web

## Objetivo

Genera una guía completa, actualizada, bien estructurada y orientada al aprendizaje sobre las mejores tecnologías para crear páginas y aplicaciones web modernas a partir del tema o requisitos que te proporcionaré al final del prompt.

## Instrucciones

Analiza el tema solicitado y desarrolla una guía organizada siguiendo una estructura lógica que facilite la comprensión, comparando tecnologías cuando resulte útil y justificando las recomendaciones.

### Estructura del contenido

Organiza la información utilizando una jerarquía clara de encabezados:

- El tema principal debe convertirse en un `<h1>`.
- Las grandes categorías deben utilizar `<h2>`.
- Los apartados específicos deben utilizar `<h3>`.
- Si es necesario profundizar más, utiliza `<h4>`, `<h5>` y `<h6>`.

Ejemplo de estructura:

```
<h1>Mejores tecnologías para crear páginas web</h1>

<h2>Frontend</h2>

<h3>HTML5</h3>

<h3>CSS</h3>

<h3>JavaScript</h3>

<h3>Frameworks Frontend</h3>

<h2>Backend</h2>

<h3>Node.js</h3>

<h3>PHP</h3>

<h3>Python</h3>

<h3>Java</h3>

<h2>Bases de datos</h2>

<h2>Herramientas de desarrollo</h2>

<h2>Despliegue</h2>

<h2>Recomendaciones finales</h2>
```

---

## Desarrollo del contenido

Para cada tecnología:

- Explica qué es.
- Describe para qué se utiliza.
- Indica sus principales ventajas.
- Expón sus posibles inconvenientes.
- Menciona en qué tipo de proyectos es recomendable utilizarla.
- Incluye ejemplos reales de uso cuando aporten valor.
- Explica su nivel de popularidad dentro del sector.
- Indica si sigue siendo una tecnología recomendada actualmente.
- Mantén un tono técnico pero fácil de comprender.
- Evita información desactualizada.
- Prioriza tecnologías ampliamente utilizadas en la industria.

Cuando existan varias alternativas similares:

- Compáralas objetivamente.
- Explica cuándo elegir una u otra.
- Destaca los casos de uso más habituales.

## Formato HTML

Genera un documento HTML5 completo:

```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tecnologías para Desarrollo Web</title>
</head>
<body>

<!-- contenido -->

</body>
</html>
```

## Diseño visual

Incluye CSS embebido dentro de `<style>` con las siguientes características:

- Diseño moderno y profesional.
- Apariencia similar a una documentación técnica.
- Anchura máxima de 1200px.
- Responsive.
- Excelente legibilidad.
- Tarjetas para cada tecnología.
- Colores diferenciados según categorías.
- Tablas modernas.
- Bloques para consejos.
- Bloques para advertencias.
- Bloques para mejores prácticas.
- Efectos hover suaves.
- Iconografía mediante emojis cuando aporte claridad.
- Índice de navegación al inicio.
- Código resaltado mediante `<pre><code>` cuando sea necesario.

## Requisitos adicionales

- Utiliza únicamente tecnologías vigentes y ampliamente recomendadas.
- Evita recomendar herramientas obsoletas salvo para explicar por qué han perdido relevancia.
- Justifica cada recomendación.
- Mantén un enfoque práctico y orientado a proyectos reales.
- Compara tecnologías cuando existan varias alternativas viables.
- Conserva una estructura clara y fácil de navegar.
- Prioriza información útil para desarrolladores tanto principiantes como intermedios.
- Si el usuario solicita un tipo concreto de proyecto (por ejemplo, una tienda online o un SaaS), adapta las recomendaciones al contexto sin perder la estructura general de la guía.
