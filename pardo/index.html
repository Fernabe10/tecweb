2. Lenguajes de Marcado Generales

2.1. Origen de los lenguajes de marcado generales: SGML y XML

  • GML y SGML – Historia: Los primeros sistemas de marcado que dieron origen a los lenguajes estructurados modernos.
  • Historia de HTML, XML y XHTML: Evolución desde SGML hacia lenguajes más simples, flexibles y orientados a la web.
  • Conceptos básicos de XML: Lenguaje diseñado para almacenar y transportar datos con estructura clara y jerárquica.

2.2. Características generales de los lenguajes de marcado

  • Combinan contenido con marcas que describen su estructura o forma de representación.
  • El lenguaje define qué etiquetas pueden usarse, dónde colocarlas y qué significado tienen.
  • Las etiquetas intercaladas reflejan la estructura y jerarquía del documento.
  • Los programas que interpretan documentos no muestran las etiquetas, solo el contenido final.
  • Conceptos clave: etiquetas, elementos y atributos.

2.3. Estructura general de un documento con lenguaje de marcado

  • Metadatos e instrucciones de proceso: Información adicional sobre el documento o instrucciones para el procesador.
  • Codificación de caracteres: Uso de UTF‑8 y caracteres especiales de escape.
  • Etiquetas o marcas: Delimitan partes del documento.
  • Elementos: Unidades estructurales formadas por etiquetas y contenido.
  • Atributos: Información adicional dentro de las etiquetas.
  • Comentarios: Notas internas que no se muestran al usuario.
