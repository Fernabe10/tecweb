Diseño Web

Planificación, diseño e implementación de páginas y sitios web

¿Qué es el Diseño Web?

El diseño web consiste en crear sitios web atractivos, funcionales y fáciles de usar. Su objetivo es ofrecer una buena experiencia al usuario mediante una correcta organización de contenidos y elementos visuales.

Elementos fundamentales

  • Navegabilidad: facilidad para desplazarse por el sitio.
  • Interactividad: permite la interacción del usuario con la página.
  • Usabilidad: facilidad de uso y comprensión.
  • Arquitectura de la información: organización lógica de los contenidos.
  • Integración de recursos: uso de imágenes, audio, vídeo y otros elementos multimedia.

Lenguajes utilizados

  • HTML: define la estructura y el contenido de la página.
  • CSS: define la apariencia y el estilo visual.

1.1. Principios de Diseño Web

1.1.1. Diseño orientado al usuario

El usuario es el centro del diseño. La web debe ser intuitiva, accesible y responder a sus necesidades.

1.1.2. Diseño orientado a objetivos

Cada página debe ayudar a cumplir los objetivos del sitio: informar, vender, enseñar o promocionar servicios.

1.1.3. Diseño orientado a la implementación

El diseño debe adaptarse a las posibilidades y limitaciones técnicas de las tecnologías utilizadas.

1.2. El Proceso de Diseño Web

1.2.1. Estructura de un sitio web y navegabilidad

Consiste en organizar las páginas y enlaces para que el usuario encuentre fácilmente la información.

1.2.2. Estructura y composición de páginas

Define cómo se distribuyen los elementos: menús, imágenes, textos, formularios y contenidos.

1.2.3. Compatibilidad con navegadores

Una página web debe visualizarse correctamente en Chrome, Firefox, Edge, Safari y otros navegadores.

1.2.4. Diseño para pantalla e impresión

El diseño web está pensado para la interacción en pantalla, mientras que el diseño para impresión prioriza la legibilidad y el aprovechamiento del papel.
