1. Diseño Web

Planificación, diseño e implementación de páginas y sitios web.

Aspectos fundamentales:
  • Navegabilidad.
  • Interactividad.
  • Usabilidad.
  • Arquitectura y distribución de la información presentada.
  • Integración de recursos: imágenes, audio, vídeo, etc.

Lenguajes

  • HTML
  • CSS

1.1. Principios de Diseño Web

1.1.1. Diseño orientado al usuario

El diseño debe priorizar las necesidades, expectativas y experiencia del usuario.

1.1.2. Diseño orientado a objetivos

Las decisiones de diseño deben alinearse con los objetivos del sitio web.

1.1.3. Diseño orientado a la implementación

El diseño debe tener en cuenta las limitaciones y posibilidades técnicas de la plataforma.

1.2. El proceso de Diseño Web

1.2.1. Estructura de un sitio web y navegabilidad

Organización de contenidos y definición de rutas de navegación para facilitar el acceso a la información.

1.2.2. Estructura y composición de páginas

Distribución de elementos visuales y contenidos dentro de las páginas web.

1.2.3. Compatibilidad con navegadores

Adaptación del sitio para garantizar su correcto funcionamiento en diferentes navegadores.

1.2.4. Diferencias entre diseño orientado a presentación e impresión

Consideración de las características específicas de visualización en pantalla frente a la impresión en papel.
