2. Lenguajes de Marcado Generales

Introducción a los lenguajes de marcado, su evolución histórica y los elementos que permiten estructurar y representar información digital.

2.1. Origen de los lenguajes de marcado generales: SGML y XML

Los lenguajes de marcado surgieron para facilitar la estructuración de documentos de manera independiente de su presentación visual. Su objetivo principal es describir el contenido y la organización de la información mediante etiquetas.

  • GML y SGML. Historia.
  • Historia de: HTML, XML y XHTML.
  • Conceptos básicos de XML.

GML (Generalized Markup Language) fue desarrollado por IBM y sirvió como base para SGML (Standard Generalized Markup Language), un estándar internacional utilizado para definir otros lenguajes de marcado.

A partir de SGML nacieron tecnologías muy importantes como HTML, orientado a la publicación web, y XML, diseñado para el intercambio estructurado de datos. XHTML intentó combinar las ventajas de HTML con la rigurosidad sintáctica de XML.

Concepto clave: XML no define etiquetas preestablecidas, sino que permite crear vocabularios adaptados a las necesidades de cada aplicación.

2.2. Características generales de los lenguajes de marcado

Los lenguajes de marcado permiten representar información de forma estructurada mediante etiquetas que describen la función y organización de cada elemento dentro del documento.

  • Combinan la información contenida en un documento con marcas o indicaciones relacionadas con su estructura o la forma de representarlo.
  • El propio lenguaje de marcas es el que especifica los tipos de etiquetas que se pueden emplear, en qué lugares pueden colocarse y el significado que tiene cada una de ellas.
  • La presencia de etiquetas intercaladas en un documento escrito con lenguaje de marcas refleja inequívocamente su estructura y jerarquía.
  • Los programas que interpretan los documentos escritos con lenguajes de marcas no suelen mostrar al usuario las etiquetas propiamente dichas, ya que este suele estar interesado en visualizar únicamente el contenido del documento.
  • Etiquetas, elementos y atributos.

Gracias a esta estructura, los documentos pueden intercambiarse entre sistemas diferentes manteniendo tanto el contenido como su organización lógica.

Importante: En los lenguajes de marcado se distingue claramente entre contenido, estructura y presentación.

2.3. Estructura general de un documento con lenguaje de marcado

Todo documento basado en un lenguaje de marcado está compuesto por diferentes elementos que permiten describir tanto la información como su organización interna.

  • Metadatos e instrucciones de proceso.
  • Codificación de caracteres. Caracteres especiales (escape).
  • Etiquetas o marcas.
  • Elementos.
  • Atributos.
  • Comentarios.

La correcta utilización de estos componentes garantiza la interoperabilidad y el procesamiento adecuado de los documentos por parte de distintas aplicaciones.

2.3.1. Metadatos e instrucciones de proceso

Los metadatos proporcionan información adicional sobre el documento, como su codificación, autoría o versión. Las instrucciones de proceso indican a determinadas aplicaciones cómo deben interpretar ciertos datos.

Estos elementos no forman parte del contenido visible, pero resultan fundamentales para el correcto tratamiento del documento.

2.3.2. Codificación de caracteres. Caracteres especiales (escape)

  • UTF-8.
  • Caracteres especiales o de escape.

La codificación determina cómo se representan internamente los caracteres. UTF-8 es actualmente la codificación más utilizada debido a su compatibilidad con prácticamente todos los idiomas.

Los caracteres especiales deben representarse mediante secuencias de escape cuando podrían confundirse con las propias etiquetas del lenguaje.

Ejemplo: el carácter "<" suele representarse como &lt; para evitar errores de interpretación.

2.3.3. Etiquetas o marcas

Las etiquetas son las marcas utilizadas para delimitar y describir elementos dentro de un documento. Habitualmente aparecen en pares de apertura y cierre.

Su función principal es indicar la estructura lógica de la información.

2.3.4. Elementos

Un elemento está formado por una etiqueta de apertura, su contenido y una etiqueta de cierre, aunque algunos lenguajes admiten elementos vacíos.

Los elementos constituyen las unidades básicas de organización de un documento marcado.

2.3.5. Atributos

Los atributos aportan información adicional a las etiquetas y permiten definir características específicas de los elementos.

Normalmente se expresan mediante parejas nombre-valor dentro de la etiqueta de apertura.

2.3.6. Comentarios

Los comentarios permiten incluir anotaciones dirigidas a los desarrolladores o mantenedores del documento sin que estas formen parte del contenido procesado o mostrado al usuario.

Son especialmente útiles para documentar estructuras complejas o dejar indicaciones de mantenimiento.

2.4. Documentos válidos y bien formados

Un documento bien formado cumple todas las reglas sintácticas del lenguaje utilizado, como el correcto anidamiento y cierre de etiquetas.

Un documento válido, además de estar bien formado, cumple las restricciones definidas por un esquema, DTD u otro mecanismo de validación.

Recordatorio: todo documento válido debe ser necesariamente bien formado, aunque un documento bien formado no tiene por qué ser válido.
